## Run locally

1. Install Visual Studio Code.
2. Open the DEXO3 project folder.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

Alternatively, open `index.html` directly in a browser. Some features, including service workers, require a local server or HTTPS.

- Use secure server-side authentication for accounts.
- Validate user-submitted information on the server.
- Use HTTPS when deploying.
