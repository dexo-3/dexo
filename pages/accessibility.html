Accessibility

DEXO3 aims to make its digital experiences usable by as many people as possible.

Our Goals

  • Clear and readable text.
  • Consistent navigation and page structure.
  • Keyboard-friendly interactive elements.
  • Meaningful labels for forms and controls.
  • Responsive layouts for different screen sizes.
  • Support for reduced-motion preferences where possible.
  • Sufficient contrast between text and backgrounds.

Ongoing Improvements

Accessibility is an ongoing process. We aim to identify and improve barriers as the website develops.

Report an Accessibility Issue

If you experience difficulty using a DEXO3 page, please use the Contact page when a working contact method is available. Include the page address and a description of the issue.

Standards

DEXO3 uses the Web Content Accessibility Guidelines (WCAG) as a reference for improving accessibility. This statement is not a claim of formal compliance or certification.
